# 音乐转 MP3（界面新版）

Windows 桌面工具：把音频文件转换成 MP3，带图形界面。

## 下载

点击 `音乐转MP3_界面新版.exe` → 右侧 `Download` 按钮下载。

## 使用

1. 下载 exe 到本地任意目录
2. 双击运行
3. 首次运行若出现 Windows SmartScreen 提示，选择「更多信息」→「仍要运行」

## 说明

- 单文件 Windows 可执行程序，约 96 MB，已内置运行库，无需另外安装 Python 或依赖
- 二进制文件直接存放在仓库中，仅用于分发
